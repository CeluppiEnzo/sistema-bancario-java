# Sistema Bancário em Java

Sistema bancário desenvolvido em Java para praticar conceitos de programação orientada a objetos e estruturas de dados.

O sistema funciona através de um menu no terminal e permite cadastrar clientes, criar contas e realizar operações bancárias básicas.

## Funcionalidades

* Cadastrar cliente
* Criar conta bancária
* Consultar saldo
* Realizar depósitos
* Realizar saques
* Realizar transferências entre contas
* Listar contas cadastradas

## Tecnologias utilizadas

* Java
* ArrayList
* Scanner
* Programação Orientada a Objetos (POO)

## Conceitos praticados

* Classes e objetos
* Encapsulamento
* Construtores
* Getters e setters
* Métodos
* ArrayList de objetos
* Estruturas condicionais
* Estruturas de repetição
* Busca de objetos dentro de ArrayList
* Relacionamento entre classes

src/

## Como executar

1. Clone o repositório:

```bash
git clone (https://github.com/CeluppiEnzo/sistema-bancario-java)
```

2. Abra o projeto em uma IDE compatível com Java.
3. Execute o arquivo `Main.java`.
